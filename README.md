# 🏰 Отырарды Қорға — тарихи интерактивті ойын (1219–1220)

Қазақстан тарихы пәні бойынша «Отырардың моңғол шапқыншылығы кезіндегі қорғанысы» тақырыбына арналған толыққанды браузерлік ойын. 1-курс студенттеріне арналған. **Толықтай қазақ тілінде.**

→ **Ойнау:** GitHub Pages қосылғаннан кейін `https://АТЫҢЫЗ.github.io/012123/` мекенжайында.

## 🎮 Ойын туралы

Ойыншы — **«Отырар қорғанысының қолбасшысы»**. 10 кезең бойы тарихи шешімдер қабылдайды:

1. **Қауіп хабары** — қорғанысты ұйымдастыру (таңдау + логикалық есеп)
2. **Барлау** — интерактивті картадан жау бағытын табу
3. **Қорғанысты ұйымдастыру** — 100 жауынгерді 4 нүктеге бөлу (drag & drop + touch)
4. **Азық қоры** — ресурс басқару шешімдері
5. **Тарихи санақ** — 20 секундтық 5 сұрақ (42 сұрақтан кездейсоқ)
6. **Қоршау** — синематикалық анимация + стратегия таңдау
7. **Отырар қақпасы** — 15 секундтық жылдам тапсырмалар (карта + қару + сұрақ)
8. **Құпия хабар** — тарихи деректі талдау + сәйкестендіру
9. **Соңғы қорғаныс** — қабырғаны жөндеу (мини-ойын) + хронология
10. **Финал** — ұпай мен ресурстарға қарай 4 атақтың берілуі

**Механикалар:** ❤️ 5 өмір · 🛡️ қорғаныс · 🍞 азық · ⚔️ әскер · 💰 қазына · ⭐ ұпай · таймерлер · localStorage-қа сақтау/жалғастыру · дыбыс (WebAudio, ON/OFF) · 42 бірегей тарихи сұрақ · SVG-карта (zoom/pan/анимация) · мобильді-дайын (320px-тен) · клавиатурамен басқару + ARIA.

## 🚀 GitHub Pages-ке жариялау (5 минут)

1. Бұл файлдарды `zhalgasbaevaaaa-create/012123` репозиторийінің **main** тармағына орналастырыңыз (мен оны алып қойғанмын).
2. GitHub-да репозиторийді ашыңыз → **Settings** → **Pages** (сол жақ мәзір).
3. **Source:** `Deploy from a branch` → **Branch:** `main` / `/ (root)` → **Save**.
4. 1–2 минуттан кейін сілтеме дайын: `https://zhalgasbaevaaaa-create.github.io/012123/`
5. Осы сілтемені студенттерге жібересіз — тіркелу қажет емес, телефонда да жұмыс істейді.

> Жаңарту керек пе? Файлды өзгертіп, `git add . && git commit -m "..." && git push` жасаңыз — Pages автоматты жаңартылады.

Қалқа шайқасы. Ойын фантастикалық элементтерді қолданбайды.
